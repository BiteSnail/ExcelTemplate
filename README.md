# ExcelTemplate – Kanboard 엑셀 양식 내보내기 플러그인

선택한 작업(태스크)을 **미리 등록한 엑셀 양식(.xlsx)에 채워서** 내려받습니다.
양식은 여러 개 등록할 수 있고, 양식마다 "Kanboard 항목 → 엑셀 치환값 `{{...}}`" 매핑을 따로 정합니다.
외부 라이브러리 없이 PHP 기본 확장(zip, dom)만 사용합니다.

## 설치
1. `ExcelTemplate` 폴더를 `kanboard/plugins/` 아래에 복사합니다. 폴더 이름은 바꾸지 마세요.
2. 처음 접속할 때 테이블(`excel_templates`)이 자동으로 만들어집니다. SQLite, MySQL, PostgreSQL을 지원합니다.
3. 요구 사항: Kanboard 1.2.20 이상, PHP `zip` 확장 (공식 Docker 이미지에는 포함되어 있습니다).

## 1. 양식 등록 (관리자)
**설정 → 엑셀 양식 → 새 양식**

1. 엑셀 파일에서 채울 자리에 `{{배포 항목}}`, `{{담당자}}`처럼 적어 둡니다. 셀 일부(`담당: {{담당자}}`)나 시트 이름에 써도 됩니다.
2. 파일을 올리고 저장하면 **양식에서 찾은 치환값**이 표시됩니다. 아직 매핑하지 않은 치환값(주황색)을 누르면 매핑 행이 바로 추가됩니다.
3. 매핑 행마다 **Kanboard 항목(Key)**을 고릅니다.
4. 필요하면 아래 항목도 정합니다.
   - **파일 이름:** 예) `배포계획서_{{배포일}}_{{제목}}`. 매핑한 치환값을 쓸 수 있고, `.xlsx`는 자동으로 붙습니다.
   - **통합 출력 방식:** 행 반복 또는 시트 반복 (아래 3번 참고)
   - **사용할 프로젝트:** 비워 두면 모든 프로젝트에서 쓸 수 있습니다.

### 쓸 수 있는 Kanboard 항목
| 구분 | 항목 |
|---|---|
| 작업 항목 (작업마다 다른 값) | 작업 번호, 순번, 제목, 설명, 참조, 프로젝트, 컬럼, 스윔레인, 카테고리, 담당자(이름), 담당자 아이디, 작성자, 상태, 우선순위, 복잡도, 색상, 태그, 마감일, 마감 일시, 마감 시간, 마감 요일, 시작일, 생성일, 수정일, 완료일, 예상 시간, 소요 시간, 하위 작업 목록, 작업 링크, **메타데이터(키 직접 입력)** |
| 문서 공통 (한 번만 채움) | 오늘, 현재 일시, 선택한 작업 수, 출력한 사용자, 현재 프로젝트, 가장 빠른 마감일, 가장 늦은 마감일, 양식 이름 |

- 날짜는 `2026-11-20` 형식, 마감 일시는 `2026-11-20 14:00` 형식입니다.
- 번호·순번·우선순위·복잡도·시간·건수처럼 숫자인 값은, 셀에 치환값만 단독으로 있으면 숫자 셀로 들어가 엑셀 수식에서 계산할 수 있습니다.
- "작업 링크"는 Kanboard 설정의 **애플리케이션 URL**을 기준으로 만들어집니다.
- 매핑하지 않은 `{{...}}`는 그대로 남으니, 빠진 매핑이 바로 눈에 띕니다.

## 2. 내보내기
- **목록 탭:** 작업을 체크하고 **작업 적용 → 선택한 작업을 엑셀 양식으로 내보내기**를 누릅니다.
  - 이 메뉴는 Kanboard 규칙상 작업을 수정할 권한이 있는 사용자에게만 보입니다.
- **작업 화면:** 왼쪽 메뉴의 **엑셀 양식으로 내보내기**를 누르면 그 작업 하나만 내보냅니다.
  - 작업 화면에서는 보기 권한만 있어도 됩니다.

창이 뜨면 양식과 출력 방식을 고릅니다.
- **통합:** 선택한 작업을 파일 하나로 받습니다.
- **각각:** 작업마다 파일을 하나씩 만들고, 여러 건이면 `.zip`으로 묶어 받습니다.

## 3. 통합 출력 방식
- **행 반복**
  - 작업 항목 치환값이 들어 있는 **첫 행부터 마지막 행까지**를 작업 수만큼 복사합니다. 한 행이면 표, 여러 행이면 묶음 단위로 반복됩니다.
  - 그 아래 내용은 아래로 밀리고, 다음 항목도 함께 맞춰집니다.
    - 수식: 예를 들어 `=SUM(E4:E4)`는 `=SUM(E4:E8)`로 늘어나고, 다른 시트에서 이 시트를 가리키는 참조도 맞춰집니다.
    - 병합 셀, 조건부 서식, 데이터 유효성
    - 인쇄 영역, 그림(결재 도장·로고) 위치, 표, 메모
- **시트 반복**
  - 작업 항목 치환값이 있는 시트를 작업마다 하나씩 복사합니다.
  - 시트 이름에 `{{제목}}`처럼 치환값을 넣으면 시트마다 이름이 붙습니다. 엑셀 규칙에 따라 31자로 자르고, 쓸 수 없는 문자는 공백으로 바꾸고, 이름이 겹치면 `(2)`를 붙입니다.
  - 시트마다 인쇄 영역, 그림, 표가 각각 복사됩니다.

> **주의:** 머리말이나 다른 시트처럼 한 번만 나와야 하는 곳에는 **문서 공통 항목**을 쓰세요.
> 예) `배포일: {{배포일}}`의 `{{배포일}}`을 작업 항목 "마감일"에 매핑하면, 그 행 또는 그 시트도 반복 대상이 됩니다.
> "가장 빠른 마감일"에 매핑하면 한 번만 나옵니다.

수식은 파일을 열 때 다시 계산되도록 표시해 두었습니다.

## 샘플
`Samples/` 폴더에 바로 써 볼 수 있는 양식이 있습니다.
- `배포계획서_표.xlsx`: 행 반복 예시 (합계 수식, 결재란, 도장 그림, 요약 시트 참조 포함)
- `배포요청서_상세.xlsx`: 시트 반복 예시 (작업마다 요청서 한 장, 체크리스트 시트)

## 알려진 제한
- `.xlsx`만 지원합니다. `.xls`, `.xlsm`은 엑셀에서 `.xlsx`로 다시 저장해 주세요.
- 반복되는 행 안의 피벗 테이블과 차트 데이터 범위는 자동으로 늘어나지 않습니다.
- 치환한 셀은 그 셀 안의 일부 글자 서식(부분 굵게 등)이 없어지고, 셀 전체 서식만 유지됩니다.
- 한 번에 최대 500건까지 내보낼 수 있습니다.

## 문제 해결
- **"양식 파일을 저장하지 못했습니다" (예전 버전: `Internal Error: Unable to write the file`)**
  - 양식 파일은 Kanboard 첨부 파일과 같은 위치(`data/files/excel_templates/`)에 저장됩니다.
  - 웹 서버 사용자가 이 폴더에 쓸 수 있어야 합니다. 예) `chown -R www-data:www-data data/files` (Docker 공식 이미지는 `nginx` 사용자)
  - SELinux를 쓰는 서버라면 `chcon -R -t httpd_sys_rw_content_t data/files`도 필요할 수 있습니다.
  - 1.0.0 버전은 Windows 서버에서 경로 구분자 문제로 이 오류가 났습니다. 1.0.1에서 수정했습니다.
